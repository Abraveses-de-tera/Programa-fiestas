#  fiesta-abraveses-2027 · Programa de Fiestas de Abraveses de Tera

Aplicación Web Progresiva (PWA) oficial del programa de fiestas de **Abraveses de Tera** (Zamora).

Acceso web: [https://abraveses-de-tera.github.io/Programa-fiestas/](https://abraveses-de-tera.github.io/Programa-fiestas/)

---

## 🌟 Características

* 📅 **Agenda Interactiva:** Consulta de actividades día a día (del 24 al 30 de agosto) o en vista completa.
* 🏷️ **Filtros por Categoría:** Música, Gastronomía, Infantil, Tradición, Deporte, Juegos y Ocio.
* 🔍 **Buscador en tiempo real:** Encuentra cualquier evento al instante por título o descripción.
* ❤️ **Mis planes (Favoritos):** Guarda tus eventos favoritos para tener tu propio itinerario personalizado.
* 👥 **Confirmación de asistencia en tiempo real:** Contador colaborativo de asistentes conectado a Firebase Realtime Database.
* 🟢 **Detección de estado en vivo:** Insignias dinámicas de *"En directo ahora"* y *"Siguiente actividad"*.
* 📤 **Compartir eventos:** Enlaces directos a cada actividad para compartir por WhatsApp, redes o copiar enlace.
* ⏳ **Cuenta atrás:** Contador dinámico para los días que faltan para las fiestas.
* 📱 **PWA y Modo Offline:** Instalable como aplicación móvil con soporte sin conexión gracias a Service Workers.
* 💬 **Comunidad:** Acceso directo al grupo oficial de WhatsApp del pueblo.

---

## 🛠️ Tecnologías utilizadas

* **Frontend:** HTML5 semántico, CSS3 moderno (Variables CSS, Flexbox, Grid), JavaScript Vanilla (ES6+).
* **Backend / Datos en tiempo real:** Google Firebase (Realtime Database + Autenticación Anónima).
* **PWA:** Web App Manifest (`manifest.json`) y Service Worker (`sw.js`).
* **Alojamiento:** GitHub Pages.
